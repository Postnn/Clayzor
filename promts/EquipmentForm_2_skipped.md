# EquipmentForm_2 — подтверждённые пропуски и отложенные решения

Пользователь подтвердил перечисленные решения. К ним нужно вернуться отдельно, не включая их в регрессионные исправления формы оборудования без нового требования.

## Подтверждённые решения

1. **`ClayDetailGrid` не использовать.** Для табличных секций применять только `ClayGrid`; предложение промта использовать `ClayDetailGrid` пропущено.
2. **Бухгалтерский учёт:** редактирование разрешено у строк, как в legacy; удаление разрешено только у последней записи. Ограничение «редактировать только последнюю строку» не вводить.
3. **Ссылки на расположение и документ:** не создавать фиктивные URL. Для ссылок нужны отдельно подтверждённые параметры конфигурации `URI_location_form` и URI формы документа.
4. **SIM → «Должность»:** поле не добавлять до подтверждения источника данных и контракта сохранения.
5. **`AutoDialNumber` / `AutoDialDelay`:** при добавлении телефонной связи не изменять до подтверждения источника задержки и контракта пары полей.

## Отложенные внешние ограничения

6. **Wake-on-LAN:** специальная операция остаётся предметом issue #3; не выдавать внешнюю интеграцию за реализованную без подтверждённого вызова и проверки.
7. **SIM detail:** отдельная внешняя детализация остаётся предметом issue #4; не подменять её локальной проекцией без подтверждённого контракта.

Все перечисленные пункты сознательно не входят в принятый объём `EquipmentForm_2`; это не скрытые заглушки текущей формы.
